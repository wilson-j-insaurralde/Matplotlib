



\# 📊 Dominando la Visualización de Datos con Matplotlib



Repositorio práctico y estructurado para aprender visualización de datos en Python desde cero hasta nivel avanzado, utilizando \*\*Matplotlib\*\*, \*\*NumPy\*\* y \*\*Pandas\*\*. 



Incluye cuadernos interactivos (`.ipynb`), personalización con hojas de estilo personalizadas (`.mplstyle`), animaciones exportadas y ejercicios prácticos.



\---



\## 🗂️ Contenido del Repositorio



El curso/taller está organizado en módulos progresivos:



| Módulo | Cuaderno | Temas Principales |

| :--- | :--- | :--- |

| \*\*01\*\* | `01\_Introducción a Matplotlib.ipynb` | Arquitectura básica, entorno y conceptos iniciales. |

| \*\*02\*\* | `02\_Primeros pasos con Matplotlib.ipynb` | Creación de figuras básicas y renderizado rápido. |

| \*\*03\*\* | `03\_Estructura de Matplotlib.ipynb` | Jerarquía: `Figure`, `Axes`, `Axis` y `Spines`. |

| \*\*04\*\* | `04\_Personalización de gráficos.ipynb` | Colores, etiquetas, leyendas, rejillas y anotaciones. |

| \*\*05\*\* | `05\_Tipos de gráficos básicos.ipynb` | Líneas, barras, dispersión (\*scatter\*), histogramas y pastel. |

| \*\*06\*\* | `06\_Gráficos avanzados.ipynb` | Diagramas de caja (\*boxplots\*), violín, mapas de calor y áreas apiladas. |

| \*\*07\*\* | `07\_Subplots y figuras múltiples.ipynb` | Métodos `plt.subplots()`, `subplot2grid` y layout flexible. |

| \*\*08\*\* | `08\_Estilos y temas.ipynb` | Creación y uso de estilos personalizados (`.mplstyle`). |

| \*\*09\*\* | `09\_Trabajando con datos en Pandas y NumPy.ipynb` | Integración directa con estructuras tabulares y arrays. |

| \*\*10\*\* | `10\_Visualización de series temporales.ipynb` | Fechas, tendencias, estacionalidad y formateo cronológico. |

| \*\*11\*\* | `11\_Visualización 3D.ipynb` | Superficies 3D, líneas tridimensionales y proyección `mplot3d`. |

| \*\*12\*\* | `12\_Interactividad en Matplotlib.ipynb` | Eventos, widgets y gráficos dinámicos en notebooks. |

| \*\*13\*\* | `13\_Animaciones.ipynb` | Uso de `FuncAnimation` y generación de archivos dinámicos (`.gif`). |

| \*\*14\*\* | `14\_Exportación y publicación.ipynb` | Resolución (DPI), formatos vectoriales (`.svg`, `.pdf`) y raster (`.png`). |

| \*\*15\*\* | `15\_Buenas prácticas en visualización.ipynb` | Criterios de diseño, contraste, accesibilidad y relación datos-tinta. |

| \*\*16\*\* | `16\_Ejercicios prácticos.ipynb` | Casos de estudio y desafíos para fijar conocimientos. |



\---



\## 🖼️ Recursos Multimedia y Estilos



\* `mi\_tema.mplstyle`: Hoja de estilos personalizada para estandarizar fuentes, paletas de color y fondos en todos los gráficos.

\* `onda.gif`: Ejemplo generado con el módulo de animaciones dinámicas.

\* `grafico.png` / `grafico\_hd.png` / `ventas.png`: Ejemplos exportados en distintas resoluciones y casos de análisis comercial.
